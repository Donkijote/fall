The app tints the supplied artwork gold using a mask.

The clean-table bonus plaque (`clean-table-plaque.webp`) was generated with
OpenAI's built-in image_gen tool on 2026-11-23 and approved for implementation
by the user. Its slimmer bronze/brass treatment references Fall's existing
brass frame, seat plaque and primary-button artwork. The selected standalone
master, original generation prompt, final edit instructions and export settings
are recorded in [the Tavern match prompt manifest](../../../../docs/design/tavern-match/prompts.json).
The model identifier is not exposed by the generation tool. Generation provenance
and approval are recorded separately from the pending provider-term review.
