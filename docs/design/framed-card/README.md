# Framed card

The [standalone brass frame](../../../src/assets/ui/surfaces/brass-frame.webp)
uses a double bevel and engraved leaf corners inspired by the Card Hall and
Rulebook mockups. Nine-slice scaling keeps the corner ornaments the same size
as the rails adapt to different widths and heights. The center uses Fall's
theme surface colors.

The brass uses a brighter, thicker static finish. The theme fill is inset and
rounded separately to fit inside the artwork corners.

ModalContent and PopoverPanel use the [rounded riveted brass artwork](../../../src/assets/ui/surfaces/riveted-frame.webp).
The modal uses a wider slice for the corner details. The select dropdown
uses a [beveled brass frame](../../../src/assets/ui/surfaces/beveled-frame.webp)
with diagonal corners. All three use nine-slice scaling and the same static
metal finish as the card. Leave Match uses the shared modal.
