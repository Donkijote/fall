# Text input

The shared field follows the [Login detailed mockup](../login/mockup-detailed.png).
The [standalone skin](../../../src/assets/ui/controls/text-input.webp) provides
the aged brass trim, inward-curved corners, and recessed charcoal face. CSS
nine-slice scaling holds the corner dimensions steady across field widths and
heights. The input and icon render independently. Focus brightens the brass and sends
a slow GSAP glint around the perimeter. Reduced motion keeps the highlight
steady. Invalid fields retain an error outline.
