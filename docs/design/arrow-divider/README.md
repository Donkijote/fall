# Arrow divider

The bronze arrow uses fixed-size end slices and a stretchable shaft. Use it
alone as a short accent or pair two inward-facing arrows around a label or
the oak sprig. Login, Rulebook, and Sings use the same standalone artwork.
The arrow and sprig are decorative and hidden from assistive technology.

Login’s intro paragraph uses a clockwise-rotated export of the same arrow.
Its shaft stretches vertically with the copy while the end slices stay fixed.

The Sings list in How to Play, the Sings Reference grid, and Hall Settings
use a gold hairline with faded ends in the artwork. Its color matches the
bronze arrow shaft. The vertical grid rule uses
a rotated export of the same image.
